## What it does

Pipeline Risk Radar continuously scores every open opportunity for stall signals, slipping close dates, missing champions and engagement decay — so revenue leaders see risk weeks before the forecast misses.

## Key features

- **Stall-signal scoring** — activity gaps, single-threaded deals, slipping milestones.
- **Forecast confidence** — commit/best-case/pipeline scored against historical accuracy.
- **Deal rescue plays** — recommended next actions per at-risk deal.
- **Manager alerts** — weekly risk digest per rep and segment.
- **CRM-native** — works on Salesforce/HubSpot data via ETL copilot.

## Who it's for

CROs, RevOps and front-line sales managers who need an honest pipeline.
